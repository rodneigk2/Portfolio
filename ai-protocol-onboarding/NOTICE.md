# Configuracao Inicial

O AI Execution Protocol ja instalou o `AGENTS.md` e os arquivos operacionais
basicos deste projeto.

Antes de continuar, escolha duas permissoes:

1. Regras locais: permite adicionar reforcos em arquivos de instrucao de IDEs
   suportadas, sempre com backup e apenas dentro deste projeto.
2. Testes reais: permite registrar resumos locais de execucoes para melhorar o
   framework, sem codigo, segredos, internet ou upload remoto automatico.

Limites importantes:

- o protocolo melhora aderencia, mas nao supera regras de sistema do host;
- controle forte exige runner, hook, gateway/proxy ou host proprio;
- voce pode recusar tudo e continuar usando apenas o `AGENTS.md` instalado.

Responda com uma destas opcoes exatas:

```text
aceito regras e testes
aceito apenas regras
aceito apenas testes
nao aceito
```

A primeira mensagem que mostrou este aviso nao sera coletada.
